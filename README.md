### 1. 문제를 정의하고 구조로 해결합니다

### 2. 기술 선택의 이유를 설명할 수 있습니다

- 익숙함이 아닌 상황에 맞는 선택을 기준으로 기술을 결정합니다

- 로컬 구현에서 끝내지 않고 배포·운영 환경까지 함께 설계
- Docker, CI/CD, 로깅, 서버 환경 구성 등 → 실제 서비스 운영을 기준으로 개발 경험을 쌓아왔습니다
