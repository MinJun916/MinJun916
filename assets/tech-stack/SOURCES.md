# Icon sources

- Brand icons: [Skill Icons](https://github.com/tandpfun/skill-icons), MIT.
- Zustand: [Devicon](https://github.com/devicons/devicon), MIT.
- TanStack and LangGraph: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0 collection; brand trademarks remain with their owners.
- Spring Data JPA uses the Spring ecosystem icon.
- SQL and QueryDSL use custom database/query symbols, not official product logos.
- Badge layout: local SVG, 40px height, 15px text, uniform light background for contrast in both GitHub themes.
